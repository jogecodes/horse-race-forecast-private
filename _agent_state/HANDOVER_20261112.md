# Horse-racing forecasting handover — November 12, 2026

## Start here: the current conclusion needs this correction

The user caught a confound in the agent-feature experiment. We previously said the
agent arm performed worse than deterministic form. The observed score difference
is real, but attributing it to additional agent information was misleading:

- Deterministic form was fitted on all 20 January development races.
- The agent arm was fitted on 16 January races, dropping four failed extractions.
- Every accepted agent form vector exactly matched the deterministic form vector.
- All five article-derived feature columns were zero for every accepted runner.
- In the preceding session, a deterministic-only refit on the SAME 16 January
  races reproduced the agent's February probabilities to maximum absolute
  difference 5.551115123125783e-17.

Thus this experiment measured the effect of different training cohorts. It did
not establish that useful agent information harms forecasting. Matching February
evaluation races alone did not resolve the training confound. The user was told
this plainly. The corrected experiment has been proposed but NOT implemented.
Older documentation and raw reports must be interpreted with this correction.

## What the market proxy means

The master DB stores post-result DG values in `result_details.dividend_raw`.
Evaluator assumes decimal gross-return semantics and calculates
q_i = (1 / odds_i) / sum_j(1 / odds_j) for the complete declared field.
No independent evidence certifies these as the final available pre-off prices.
There is no usable historical T−60 price cohort. Verified closing coverage for
this development run is explicitly zero: metrics null, not fabricated.

Proxy filtering excludes whole races with missing declared-runner prices,
non-numeric/less-than-one values, or suspected duplicated margin/time fields.
No runner is dropped or assigned an invented price. Capture URL/hash/date receipts
are saved; quote timestamps remain unknown. There are 30 complete proxies across
48 development races, 17 in February. The agent's successful February subset has
12 proxies. Normalized inverse prices are not proof that the market probabilities
are calibrated. Proxy scores do not establish executable betting returns.

Brier is sum_i((p_i-y_i)^2) per race, averaged equally across races; lower is
better. y uses benchmark winning shares for dead heats and preserves the declared
field including later nonstarters. Model-minus-market error is paired on exact
same fields and outcomes; negative favours model. Squared model-market distance
measures disagreement only. Do not mix this multiclass score with earlier pooled
binary Brier numbers.
